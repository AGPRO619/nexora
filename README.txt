NEXORA 5 independent app package. Upload all HTML files and apps.json to the ROOT of AGPRO619/nexora/main (no folders). Replace nexora.html with the included launcher. Each app file contains only that app and its necessary data/helpers; GraphForge is the original standalone GraphForge. Update a single app file to update it in the launcher. External APIs require network and may require keys. Some integrations require HTTPS or third-party permissions. No browser end-to-end tests have been performed. Keep private keys out of public repositories.
